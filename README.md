# G4Z CUP — партнёрский лендинг

Статический сайт для знакомства с проектом G4Z CUP, примерами партнёрских интеграций и организацией турниров для компаний.

## Структура

- `index.html` — содержание страницы и метаданные.
- `style.css` — оформление, адаптивная вёрстка и анимации.
- `script.js` — фоновые видео, появление блоков и вкладки примеров размещений.
- `assets/` — изображения, видео, логотип и локальные шрифты.

## Локальный запуск

Из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8000>. Установка зависимостей и сборка не требуются.

## Публикация

Разместите `index.html`, `style.css`, `script.js` и каталог `assets/` на статическом хостинге, сохранив относительные пути. Серверная часть и переменные окружения не используются.

Публичный адрес лендинга — `https://g4z-cup.online/`. В `index.html` настроены canonical, Open Graph и Twitter Card с абсолютными ссылками на этот адрес. При смене домена обновите эти ссылки. Обложка для соцсетей — `assets/social-card.png` (1200 × 630).

## Оформление и доступность

CSS отформатирован по блокам; общие размеры текста, подписей и меток задаются переменными `--copy-size`, `--caption-size` и `--label-size`. Порядок правил сохранён, а перекрытые декларации удалены.

Для клавиатуры предусмотрены переход к основному содержанию и контрастные индикаторы фокуса. Во вкладках примеров работают стрелки влево/вправо, Home и End. Учитывается `prefers-reduced-motion`, в том числе при его включении на открытой странице. Без JavaScript основные блоки видны, а все примеры интеграций раскрыты.

Фоновое видео плавно появляется после готовности первого кадра. До этого виден постер; при переключении между роликами предыдущий кадр остаётся на экране до готовности следующего. Самим видеофайлам перекодирование не требуется.

## Проверка JavaScript

При установленном Node.js:

```sh
node --check script.js
node --test tests/video-background.test.cjs
```
